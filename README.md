# Digital Communication IC Design (DCIC)

Coursework for **Digital Communication IC Design (數位通訊積體電路設計)**, National Tsing Hua University, Fall 2025 (114-1).

The assignments build an IEEE 802.11-style OFDM baseband receiver step by step: from a split-radix FFT, through floating- and fixed-point MATLAB models, to Verilog RTL. The final project extends it into a 2×2 MIMO-OFDM receiver.

## Repository layout

| Folder | Topic | Contents |
|---|---|---|
| [`HW1-SRFFT`](HW1-SRFFT) | Split-radix FFT | MATLAB and C implementations, Simulink models (`.slx`), report |
| [`HW2-OFDM-Baseband`](HW2-OFDM-Baseband) | OFDM transceiver model | QPSK/16-QAM mapping, IFFT/FFT, CP insertion and removal, AWGN channel, symbol sync |
| [`HW3-Fixed-Point-Sync`](HW3-Fixed-Point-Sync) | Fixed-point simulation & synchronization | STS/LTS preamble sync, fixed-point FFT/demapper, BER and constellation plots |
| [`HW4-OFDM-RTL`](HW4-OFDM-RTL) | OFDM receiver RTL | Verilog (`OFDM_top`, butterfly, sync), test patterns, FPGA reports |
| [`Final-MIMO-OFDM`](Final-MIMO-OFDM) | 2×2 MIMO-OFDM receiver | MATLAB system model, Verilog RTL, testbench, synthesis scripts, FPGA reports, final report & slides |

Each homework folder has a `report/` folder with the submitted report (PDF).

## Final project: MIMO-OFDM receiver

**System model:** `software/MIMO_OFDM_main.m`
- Legacy and HT preambles
- STS/LTS timing and frequency synchronization
- Channel estimation and MIMO detection
- Fixed-point sweep for word-length selection

**RTL:** `hardware/hdl/`, top module `MIMO_OFDM_top.v`
- 64-point radix-2³ SDF FFT (`FFT_64.v`, `PE_radix23.v`, `Rotator*.v`)
- Short- and long-preamble synchronization (`sync_short.v`, `sync_long.v`)
- Channel estimation and preprocessing (`channel_est.v`, `channel_prepocessing.v`)
- MIMO detection (`MIMO_detection.v`) and QAM demapping (`QAM_demap.v`)
- Ping-pong buffering and a top-level FSM

**Verification:** `hardware/sim/` has a VCS testbench, run with `run_presim.sh`. The test patterns in `sim/data/` are generated by the MATLAB model.

**Results:** Vivado 2018.1, Virtex-7 (xc7vx485t), routed

| Design | LUTs | FFs | DSPs | BRAM tiles | WNS |
|---|---|---|---|---|---|
| HW4 OFDM receiver | 7,768 | 8,250 | 30 | 0 | — |
| Final MIMO-OFDM receiver | 7,065 | 3,650 | 244 | 12 | +0.453 ns |

The design was also synthesized and taken through APR in a 90 nm standard-cell flow (see the final report and `figures/layout.jpg`).
